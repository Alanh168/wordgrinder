# Wordgrinder's Game Overview
Wordgrinder offers the user the option of turning their daily word count tracking into a terminal-based game. 

The game's features are able to be toggled on or off. Toggling Off removes certain UI elements pertaining to the game

## Game Elements and their Menu Items (Under Game Main Menu Item):
### Character
The user has a character that is represented by a character sprite (visible in the Character Menu Option as well as the Statistics Menu Option).

### Equipment 
Every character has currently equipped armor, weapons, and obtained monsters (all 3 are known collectively as Equipment). Each armor and weapon item can be equipped to one of 7 parts of a character sprite (Head, Torso, Left Arm, Right Arm, Left Leg, Right Leg, and Back). Obtained Monsters are equipped alongside the character sprite, not on their person (up to 6 obtained monsters equippable at one time). The Equipment screen has 3 pages:
    1. Currently equipped Equipment
    2. Unequiped Equipment that the user has obtained
    3. Equipment that hasn't been obtained yet.

### Map
Where the character is on the map is project-dependent (as opposed to Characters, Equipment, Monsters, and Quests which exist independent of what proejct you're on). The map is called Writer Region and it has 7 locations:
    1. Idea Town
    2. Brainstorm Valley
    3. 1st Draft City
    4. Self-Revision Cave
    5. Workshop Town
    6. Notes Falls
        - To enter the Falls, user must submit all the notes they received on their story from Workshops / Other people. Then, when traversing the Falls, each item on the list becomes a peice of terrain they have to cross through (spiky rocks, strong wind tunnels, animals crossings, etc). Each terrain prompts the user, asking them if they have either dismissed the note or insorporated it into their new draft. A yes gets them past the terrain.
    7. Final Draft Colloseum

### Monsters
Monsters: On the Battle Select Screen, the user can select what monsters to put on a queue to "fight" for exp, money, and/or items. Every monster type has a certain number of words needed to be written (while the monster is 1st on the Battle Queue) in order to defeat the monster. In addition to a required word count, some monsters have an additional number of time (usually in minutes) that the user is given to write the monster's word count. If the user has a monster at the front of their Battle Queue, and the write the monster's required word count in the monster's time limit (some mosnters don't have time limits) they successfully defeat that monster.

### Quests
Quests: The user can take on quests on the Quest Screen. On the Quest Screen there are 3 pages:
    1. Currently accepted Quests
    2. Available to Select Quests
    3. Completed Quests
